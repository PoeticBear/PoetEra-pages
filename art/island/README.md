## 原型素材

- `terrain.svg`：水面、岸壁、岛面、步道和小洲。
- `mountain.svg`、`tree.svg`、`bamboo.svg`：山石、树木和竹丛，可复用的独立层。
- `pavilion.svg`、`house.svg`、`dock.svg`、`bridge.svg`：亭子、屋舍、渡口和跨水木桥。
- `boat-0.svg` 至 `boat-7.svg`：八向小舟；水面锚点为原图 `(90, 60)`。
- `manifest.json`：原始尺寸；其他物件使用底边中点作为摆放锚点。
- `map-preview.svg`：同一批物件组成的静态地图，供首次加载与渲染失败时使用。

重新生成：`node scripts/build-island-art.mjs`。源码与生成文件一同保留；更改尺寸时同时检查场景锚点和命中区域。

这些图形是本项目的体验原型素材，可随项目使用和继续修改。这里的岛屿、建筑、路线、船客及画面天气均为艺术表现，不是黄州古地图、宋代建筑考证、苏轼肖像或行程复原。史实与文学出处由正文独立提供。

## 正式素材制作

体验确认后，可以由插画师沿用相同机位、比例、锚点及分层规范，逐件替换为青绿山水或纸本设色素材。应交付透明底独立物件、八向船、遮挡层和降级静态合成图，并记录作者、使用授权、修改权和来源。历史风貌若进入正式复原范围，需另行完成考据；不能将美术替换当作史实验证。

首轮无需整幅大型背景图或三维模型。当前 16 张场景 SVG 合计 42,176 字节，静态合成图 69,764 字节；按原始尺寸计算，单套场景纹理的 RGBA 像素约 8.72 MiB，不含帧缓冲、字体纹理和浏览器解码开销。
