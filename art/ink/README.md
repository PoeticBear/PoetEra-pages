# 水墨黄州 · 分层画境素材

制作日期：2026-11-16。用于独立 `/ink` 入口，纸白、淡灰与墨黑组成连续江岸。原版画册和 `/world` 小岛素材不变。

## 来源与使用

四张原始图由 Codex 内置 `image_gen` 工具为本项目生成，竹枝另外经过同一工具定向修整透明边缘；没有下载第三方古画或地图。完整生成与修整提示词保存在 [prompts.json](prompts.json)。`scripts/build-ink-art.mjs` 使用现有 sharp 调整尺寸、保留 alpha、编码 WebP，并按场景坐标合成静态画面。

这些是 AI 辅助原创艺术素材，可随 PoetEra 项目使用和继续修改，沿用本项目插画使用约定；不暗示专有版权、苏轼真实肖像、黄州历史地貌或史实证据。作品原文和历史说明仍以已发布内容及其来源为依据。

## 文件与图层

| 文件 | 用途 |
| --- | --- |
| `landscape.webp` | 完整连续底画，包括纸纹、远山、江面、岸线、竹汀、屋舍与石亭；前景移动后不会露出未绘区域 |
| `mountains.webp` | 透明远山与淡雾，低透明度装饰视差层 |
| `foreground.webp` | 透明竹枝，左右近景复用，形成遮挡与少量叶动 |
| `boat.webp` | 透明小舟，宽 148 世界单位，等比缩放；水面锚点为 `(0.5, 0.76)` |
| `preview.webp` | 同一组图层的完整静态合成图，首屏与渲染失败时使用 |
| `mobile-study.webp` | 390 × 844 竖屏构图参考，仅供检查，不进入页面首屏加载 |
| `manifest.json` | 输出尺寸、alpha、逐项字节数和首屏美术总量 |

世界坐标为 2400 × 1400。交互岸线、建筑和命中区域共同使用底画坐标；仅远山和近景竹枝做独立视差，避免岸签与舟位错开。建筑与岸线在本轮底画中保持完整绘制，未制作可单独移动的建筑物件。纸纹和主要山体稳定，水纹着色器仅作用于河道内的线纹。

## 重建与检查

将四张原始 PNG 以 `landscape.png`、`mountains.png`、`foreground.png`、`boat.png` 放入本地输入目录，再运行：

```bash
node scripts/build-ink-art.mjs tmp/ink-source
```

生成原图保留在本机 Codex generated_images 中；项目运行只依赖当前目录已交付的 WebP。构建脚本无需调用生成服务。不同设备重建时需要提供原图；`prompts.json` 用于溯源及再制作，无法保证重新生成相同像素。

已离线检查整幅及手机裁切：舟与竹汀可辨，透明图层未带实色矩形，船体保持横向比例，远山顶边被安排在画外。静态合成只验证构图和素材，不代表实际浏览器排版、GPU 帧率、触屏或横竖屏体验通过验收。首屏预算以 `manifest.json` 和导出校验脚本的实际统计为准；未把 30 fps 目标表述为性能保证。
