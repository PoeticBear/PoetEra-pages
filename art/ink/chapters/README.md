# 苏轼行旅 · 杭州与密州画境

制作日期：2026-11-16。两张独立背景由 Codex 内置 `image_gen.imagegen` 辅助创作；完整最终提示词保存于 [prompts.json](./prompts.json)。没有使用外部馆藏图片、网络风景照或字体图像。

## 场景与时期

- `hangzhou.webp`：呼应苏轼熙宁年间初任杭州通判（1071–1074）的西湖作品。青绿淡墨、柳岸、湖上亭榭、荷汀与远山；不画后来任杭州知州期间修筑的苏堤，也不表现现代西湖建筑。
- `mizhou.webp`：呼应密州知州时期（1074–1076）的出猎、超然台与中秋词。暖赭淡墨、北方疏林、低丘、台榭和淡月。将不同季节与作品意象组织在同一画中，不表示三首词写于同日，也不是超然台建筑考证图。

每张画的岸点、水面和视角均为交互阅读服务。尤其密州的连通水道是统一行舟交互的文学意象，并不主张苏轼曾乘舟按此路线到达各创作地点。画面、木牌及船只的屏幕位置不作地理定位依据。

## 文件与复用

- 两张背景均为完整平面水墨画，1920 × 1120；映射到 2400 × 1400 的画境坐标。山峦与前景已绘入背景，因此不再叠加黄州的竹枝、山峦图层。
- `hangzhou-preview.webp`、`mizhou-preview.webp` 为无 JavaScript／WebGL 时的静态首屏，按渡口初始位置合成既有 `/art/ink/boat.webp`，船体宽度为 148 世界单位，中心 x=730、水线 y≈1010。
- 运行时复用既有小舟、波纹、木牌和操作方式；背景与静态首屏按篇章加载。
- `manifest.json` 记录每项文件的实际尺寸、字节数与 SHA-256。构建只做尺寸归一、WebP 编码与静态船只合成；生成原图保留在 Codex 的 generated_images 中，项目运行只引用本目录已保存的成品。

## 使用信息

AI 辅助原创插画，作为本项目美术素材使用，随项目许可证分发；不是历史实景复原、传世古画、馆藏数字化复制品或苏轼本人绘画。未新增第三方图像授权要求。原有船只的来源与说明沿用 [黄州画境美术说明](../README.md)。

已检查两个背景无文字／水印、风格及地方元素有区别、行舟水面连通，静态预览保留船体正常比例。文件检查不代替实际浏览器的构图、遮挡及交互验收。
